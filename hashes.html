Etapa 3 de 3

🧬 Funciones hash: comprobar que no fue modificado

Descargaste un mod para Minecraft. ¿Cómo sabés que realmente lo hizo quien dice haberlo hecho, y que nadie lo modificó en el camino para meterle un virus?
Encontraste un hack para tu juego favorito. ¿Cómo podrías saber si el archivo fue alterado antes de instalarlo?

Ni la criptografía ni la esteganografía resuelven este problema: cifrar oculta el contenido, ocultar oculta la existencia, pero ninguna de las dos te dice si el archivo que tenés en tus manos es exactamente igual al que se envió. Para eso existen las funciones hash.

¿Qué es una función hash?

Una función hash toma cualquier entrada (una palabra, un párrafo, una foto, un instalador entero) y produce una salida de tamaño fijo — una especie de huella digital del contenido. Tiene tres propiedades clave:

Determinística

La misma entrada siempre produce exactamente el mismo hash.

Unidireccional

No existe forma de "deshacer" un hash para recuperar el contenido original — no es cifrado.

Efecto avalancha

Cambiar un solo carácter de la entrada produce un hash completamente distinto.

Herramienta: calculadora de hash (SHA-256)

SHA-256 es el algoritmo que usan, entre otros, Bitcoin, Git y la verificación de descargas de software.

Nota para el equipo docente: el hash oficial de este ejemplo no corresponde al texto mostrado a propósito — la actividad busca que el grupo detecte la alteración. Pueden reemplazar ambos valores por un ejemplo propio calculado con la calculadora de arriba.

Hash no es cifrado: un archivo cifrado se puede descifrar con la clave correcta. Un hash nunca se "deshace": solo sirve para comparar. Por eso las apps y sitios web no guardan tu contraseña tal cual la escribís — guardan su hash, y comparan hashes cuando iniciás sesión.

Cerrando la misión

Ya tienen las tres piezas: un mensaje cifrado, oculto en una imagen, y una forma de comprobar que no fue alterado. Es hora de ponerlas todas juntas.
